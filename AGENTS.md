# WordClone — Agentic Document Editor

## Commands

| Command | Action |
|---------|--------|
| `pnpm dev` | Electron + Vite HMR |
| `pnpm build` | typecheck → build (always runs typecheck first) |
| `pnpm lint` | ESLint flat config (`eslint.config.mjs`) |
| `pnpm format` / `pnpm format:check` | Prettier (no semi, single quote, 100 width) |
| `pnpm typecheck` | runs `typecheck:node` + `typecheck:web` |
| `pnpm test:smoke` | single test: file format detection/conversion |
| `pnpm test:docx-roundtrip` | generates fixtures + validates DOCX round-trip |
| `pnpm test:fixtures:generate` | regenerate DOCX fixtures only |

## Test framework

Node built-in `node:test` + `node:assert/strict` + `tsx` (NOT Jest/Vitest).  
Tests are `.test.ts` files anywhere in the tree. Use `tsx --test <path>` to run individual files.

## Architecture (three-process Electron)

- **`src/main/`** — window lifecycle, IPC handlers (`ipc/`), agent loop runner (`agent/`)
- **`src/preload/`** — `contextBridge` exposing `window.api` (namespaces: `window`, `file`, `settings`, `ai`, `agent`)
- **`src/renderer/`** — React 19 app with Zustand stores (`store/`), ribbon/chrome UI (`components/`), editor bridge (`editor/`), agent system (`ai/`)
- **`src/shared/`** — types shared across processes: models, agent tools (`agentTools.ts`), agent session protocol (`agentSession.ts`)
- Renderer alias: `@renderer` → `src/renderer/`

## Agent system

- Two modes: `'agent'` (direct tool execution) and `'plan'` (submit plan via `submit_plan` tool first)
- Edit tools create suggestion diffs via `proposeChange()` — user accepts/rejects tracked changes
- Tools defined in `src/shared/agentTools.ts` as `READ_TOOLS` + `EDIT_TOOLS` + `SUBMIT_PLAN_TOOL`
- Agent execution in `src/renderer/ai/agent.ts` (AgentController), tools dispatched via `toolDispatcher.ts`
- Main-process agent loop runner in `src/main/agent/` (`loopRunner.ts`, `sessionManager.ts`, `contextManager.ts`)
- Max 15 tool-calling rounds per request; up to 20 blocks per `insert_blocks`, 15 ops per `batch_edit`

## Key dependencies

- `@eigenpal/docx-editor-react` / `@eigenpal/docx-editor-core` / `@eigenpal/docx-editor-agents` — native OOXML editing
- `@google/genai` — Gemini SDK (NOT `@google/generative-ai`)
- `zustand` — state management
- `electron-vite` + `@tailwindcss/vite` + `lucide-react`

## Config & style

- `.editorconfig`: LF, 2-space indent, UTF-8
- `.prettierrc`: `{ semi: false, singleQuote: true, printWidth: 100, trailingComma: "none" }`
- ESLint: `@typescript-eslint/no-explicit-any: 'off'`, unused vars warn with `^_` ignore
- TypeScript 6 with strict mode (via `@electron-toolkit/tsconfig`), separate `tsconfig.node.json` / `tsconfig.web.json`
- Electron: `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`, frameless window
- API keys encrypted via `safeStorage`
- `.doc` import requires LibreOffice headless (`soffice` / `libreoffice`)

## DOCX fidelity

- Fixtures in `tests/fixtures/docx/` generated by `tests/scripts/generate-docx-fixtures.mjs`
- Open/save uses raw `ArrayBuffer` over IPC (no mammoth/html-to-docx)
- See `docs/DOCX_FIDELITY.md` for known eigenpal gaps
