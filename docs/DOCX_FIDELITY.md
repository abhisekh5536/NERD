# DOCX Fidelity Benchmark

WordClone uses native OOXML editing via `@eigenpal/docx-editor`. This document tracks fidelity expectations and test results.

## Test corpus

Fixtures live in `tests/fixtures/docx/` (generated by `tests/scripts/generate-docx-fixtures.mjs`):

| Fixture | Covers |
| --- | --- |
| `simple-letter.docx` | Paragraphs, bold, italic, paraIds |
| `headings-lists.docx` | Heading styles, bullet/numbered text |
| `table-basic.docx` | Simple 2×2 table |

Additional corpus items (header/footer, images, section breaks, track changes) can be added as real-world samples are collected.

## Automated checks

Run:

```bash
pnpm run test:docx-roundtrip      # generates fixtures + validates structure + eigenpal round-trip
pnpm run test:fixtures:generate   # regenerate fixtures only
```

The round-trip test:

1. Verifies each fixture contains required OOXML parts (`word/document.xml`, `[Content_Types].xml`)
2. Parses each fixture with `DocumentAgent.fromBuffer()` from `@eigenpal/docx-editor-core`
3. Re-serializes via `agent.toBuffer()` and confirms the output is a valid DOCX package

## Manual gate (spike sign-off)

Open these fixtures in WordClone (`pnpm dev` → File → Open) and compare side-by-side with Microsoft Word:

1. `tests/fixtures/docx/simple-letter.docx`
2. `tests/fixtures/docx/table-basic.docx`

Acceptable deltas follow [eigenpal's fidelity matrix](https://www.docx-editor.dev/docs/1.x/word-fidelity) (e.g. multi-column renders single-column but round-trips).

## Known eigenpal gaps

- Multi-column layout: preserved on save, renders single-column
- Some fields, text boxes, embedded OLE objects may diverge
- Legacy `.doc` requires LibreOffice conversion in the main process
- `set_page_setup` / `set_page_numbers` agent tools return a not-yet-implemented message; section properties from opened files are preserved

## Architecture notes

- DOCX open/save uses raw `ArrayBuffer` over IPC — no mammoth or html-to-docx
- AI edits use `proposeChange()` (track changes) with accept/reject via ProseMirror revision commands
- Print uses eigenpal's `editor.print()` for paginated OOXML layout
